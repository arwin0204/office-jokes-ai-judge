A tiny deterministic program that writes one original one-line office joke (132 characters) to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. No randomness, no network, no clock — the same joke every run. The joke plays on the classic "we're a family here" office line, with a twist at the end.

## Run it

```sh
node main.ts
```
